Como funciona?

  1. 1Copie as mensagens do grupo do WhatsApp.
  2. 2Cole no campo "Mensagens brutas" (pode ser várias de uma vez).
  3. 3Clique em “Ler mensagens” para o sistema identificar.
  4. 4Revise os dados na próxima etapa (Conferência).

Escolha uma vez onde salvar. Depois, toda vez que você gravar um time, o arquivo é atualizado sozinho.
